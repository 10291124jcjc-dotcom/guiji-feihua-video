# 动画引擎 API（scripts/wb.py）

写 scenes.py 时查这里。画布 1920×1080，30fps。坐标单位是像素，原点在左上角。

1. 场景与时间

## 1. 场景与时间

每个场景函数收到一个 `Scene` 对象 `s`：

| 用法 | 含义 |
|---|---|
| `s.t(i, frac)` | 第 i 句（从 0 数）开始后 `frac` 比例处的秒数。**元素挂在念到它的那句上** |
| `s.add(e1, e2, [e3, e4], ...)` | 按顺序加入元素，列表会展开 |
| `s.erase(t, dur=0.55, keep=(...))` | t 秒时用板擦擦掉这一块板上的东西，tag 在 keep 里的保留 |
| `s.T` | 场景总时长（旁白 + 结尾留白） |
| `s.ctx.st / s.ctx.du / s.ctx.end` | 每句开始时间 / 时长 / 最后一句结束时间 |
| `s.squeezed` | 被自动压缩的段落（build.py audit 会报告） |

每个元素的时间参数：

| 参数 | 含义 |
|---|---|
| `at=秒` | 最早什么时候开始画 |
| `chain=True`（默认） | 排队：等上一笔画完（+0.12 秒抬笔）才画，且不早于 `at` |
| `chain=False` | 并行：到 `at` 就画；没给 `at` 就和上一个元素同时开始 |
| `dur=秒` | 画多久（不填按长度自动估算：描边约 1100px/s，汉字约 0.055~0.2 秒/字） |
| `z=0/1/2/3` | 图层，大的在上。0=集中线，1=默认，2=气泡白底，3=气泡边框和文字、印章 |
| `tag="year"/"thermo"/"wm"` | 擦板时可以保留的元素 |

**自动压缩**：`s.erase()` 发现这一块板没在擦板前画完，会把这块板的时间轴整体按比例压缩，保证不会"擦完又冒出来"。但被压缩说明画面落后于旁白，最好改成并行，而不是依赖压缩。

## 2. 元素

| 元素 | 说明 |
|---|---|
| `Text(x, y, 文字, size, color, align="left/center/right", bold=0.8, fnt=KAI)` | 手写文字，逐字写出。`\n` 换行。y 是文字顶部。`bold` 是描边粗细（1~3 为标题） |
| `Stroke(paths, color, w)` | 任意手绘线，`paths=[(点列表, 是否闭合), ...]`，双遍描边有手绘感 |
| `Portrait(人物id, cx, bottom, scale=0.85, crop_bottom=None)` | 漫画人像：先勾墨线再铺网点。`cx` 中心，`bottom` 底边 y。`scale=0.8` 时约 430×570 |
| `Img(PIL图, x, y, mode="wipe/pop/fade", anchor="tl/c/b")` | 贴图。`pop`=印章砸下来，`wipe`=从左往右画出 |
| `Fill(多边形, color)` | 实心填充，瞬间淡入（气泡白底、色块） |

## 3. 常用画法（都返回元素，可以直接 `s.add`）

| 函数 | 用途 |
|---|---|
| `line(p0, p1, color, w)` / `poly(点, color, w, closed)` / `rect(x0,y0,x1,y1,...)` | 基本线条 |
| `ellipse(cx, cy, rx, ry, color, w, turns=1.08)` | 手绘圈（`turns>1` 首尾会交叠，像真人画的） |
| `arrow(p0, p1, color, w, curve=0.2)` | 手绘弧线箭头 |
| `underline(x0, x1, y, RED, w, double=False)` / `wavy(x0, x1, y, RED)` | 下划线 / 波浪线 |
| `hachure(凸多边形, YELLOW, gap=12)` | 斜线阴影填充。**只支持凸多边形** |
| `speed_lines(cx, cy, rx, ry)` | 漫画集中线（z=0，垫在最下面） |
| `crack(x, y0, y1)` | 红黑裂缝，**返回列表** |
| `stick_person(cx, bottom, h, arms="down/wide")` | 火柴人（代表群体或无关人物，不要画成真人） |
| `bubble(cx, cy, rx, ry, 尾巴坐标, 文字, size)` | 漫画对白气泡，**返回列表** |
| `year_box(x, y, "2016", tag="year")` | 左上角年份框，**返回列表** |
| `stamp_img(文字, size, rot)` / `sfx_img("咔嚓！")` | 印章图 / 拟声字图，配合 `Img(..., "pop")` |
| `not_nonsense(x, y, rot)` | 品牌「不是废话」红章（已经是 Img） |

颜色：`INK` 墨黑、`RED` 品牌红、`GRAY` 灰（注释、次要信息）、`YELLOW` 黄（阴影填充）。
字体：`KAI` 楷体（默认，手写感），`HEI` 微软雅黑粗体（拟声字、印章）。

## 4. 画面安全区与布局习惯

- **字幕带**：y > 950 留给字幕，不要放重要元素（人像下半身可以伸进去）。
- **水印**：右上角 x > 1590、y < 135。
- **关系温度计**：右下角 x 1790~1900、y 540~900。用了温度计的期，右侧内容不要超过 x=1760。
- **年份框**：左上角 (60, 40) 起。
- **标题**：y≈60~120 居中；人物档案标题 54px，正文 34~40px，大标题 72~120px。
- **人物**：左人 cx≈320~440，右人 cx≈1480~1590，bottom=1080，scale 0.72~0.82。朝右看的人放左边，朝左看的放右边。
- 一块板上 3~6 个元素最舒服，太满就用 `next_panel` 换一块板。

## 5. 常见坑

- **画面落后于旁白**：同一句挂了很多元素、全都 `chain=True`，就会越排越晚。解决：几路并行（`chain=False` + 各自的 `at`），或者给元素设更短的 `dur`。`build.py audit` 能查出来。
- **楷体缺字**：✍ ↩ 🚫 这类符号和 emoji 在楷体里是方框，只用普通汉字和标点（← → ↑ ↓ ↗ · × 可以）。
- **hachure 用于凹多边形会报错**（比如闪电形状）：改用 `Fill`。
- **Text 的 y 是顶部**，不是基线；居中文字要 `align="center"`，x 是中心。
- **擦板保留**：`next_panel` 会保留年份框、温度计、水印；`end_erase` 会擦掉年份框（换场景要重画年份）。
- 每个场景都要调用 `watermark(s)`（第一个场景传 `draw_at` 让它被画出来），最后调用 `end_erase(s)`。
