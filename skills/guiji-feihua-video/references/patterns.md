# 版式模板（scripts/patterns.py）

scenes.py 开头 `from patterns import *` 就能用。模板只负责画一块板，不擦板。
需要更细的控制时，直接用引擎元素手写（见 engine-api.md），示例期（example-episode/scenes.py）里大部分场景就是手写的。

## 每个场景的固定骨架

```python
def sc_xxx(s):
    watermark(s)                      # 每个场景都要（第一个场景用 watermark(s, draw_at=0.05) 或 title_page(first=True)）
    thermo(s, 0.6, 0.3, s.t(0, 0.4))  # 可选：关系温度计，0.6→0.3 在第 0 句 40% 处变化
    ...                               # 版式 / 元素
    end_erase(s)                      # 每个场景最后都要（最后一个场景用 end_card 代替）
```

同一场景里换一块板：`next_panel(s, 2)`（在第 2 句开头擦板）。

## 模板一览

| 模板 | 什么时候用 | 用法 |
|---|---|---|
| `title_page(s, 标题, left, right, crack_sent=1, first=True)` | 开场 | 大标题 + 双下划线，可选两人对视、名字、裂缝 |
| `profile_pair(s, 左id, 右id, 左rows, 右rows, 0, 1)` | 介绍两个人 | 每人 3 行短句，第 0 句讲左人、第 1 句讲右人 |
| `compare_table(s, 标题, 左表头, 右表头, rows, mark=4, stamp_row=4)` | A vs B 对比 | `rows=[(左, 右, 左出现的句, 右出现的句)]`，句也可写成 `(句, 比例)` |
| `timeline(s, 标题, events, left, right)` | 时间线 | `events=[("2017", "RLHF\n人类反馈", 句, 比例)]`，最多 4 个 |
| `big_number(s, "1 亿", "两个月用户数", sent=0, pid=None)` | 一个惊人的数字 | 超大红字 + 红圈 + 「不是废话」章 |
| `quote(s, 人物id, "金句\n第二行", sent, side="right")` | 引用某人原话 | 人像 + 对白气泡 + 署名。**只放真实说过的话** |
| `climax(s, 左id, 右id, "咔嚓！", sent)` | 全片最高潮 | 集中线 + 两人 + 裂缝 + 拟声字。**一期最多用 1~2 次** |
| `bullets(s, 标题, items, pid=None)` | 要点清单 | `items=[(文字, 句, 比例)]` |
| `question(s, "你站哪边？", sent)` | 结尾提问 | 超大问题 + 波浪线 + "评论区聊聊" |
| `end_card(s)` | 最后一个场景结尾 | 品牌卡 + 资料来源 + 照片署名（自动读 episode.json），静音 6.5 秒 |

## 品牌固定元素（每期都有）

- **水印**：右上角「硅基废话」+「AI 合成配音」标识。配音是克隆音色，这个标识要保留。
- **「不是废话」红章**：`not_nonsense(x, y)`，盖在本期最硬的 1~3 个事实上（关键数字、关键转折）。盖多了就不稀罕了。
- **关系温度计**：`thermo(s, lv0, lv1, t_change)`。讲人和人、公司和公司关系的题材用，从热（1.0）到冰点（0.05）。跨场景保持连续：上一场景的 lv1 = 下一场景的 lv0。纯技术新闻可以不用。
- **漫画对白框字幕**：build.py 自动加，不用管。
- **片尾卡**：`end_card(s)`，口号「都是废话，盖了章的除外」。

## 场景节奏建议

- 新闻类：1~2 分钟、5~6 个场景：开场钩子 → 发生了什么 → 关键数字 → 为什么重要 / 各方反应 → 结尾提问。
- 人物恩怨类：可以长（第一期 5 分半、12 个场景），按时间线推进，温度计贯穿。
- 每句旁白最好对应画面上的一个新元素；超过 8 秒没新东西画出来，观众就会走神。
